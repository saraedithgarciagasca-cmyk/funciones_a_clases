# De funciones a clases

Práctica de Programación Aplicada: tres ejercicios resueltos antes con funciones,
ahora implementados con una clase cada uno.

## Estructura

```
funciones_a_clases/
├── clases/
│   ├── __init__.py
│   ├── ejercicio1_compra.py        # clase CompraTienda
│   ├── ejercicio2_calificacion.py  # clase Calificaciones
│   └── ejercicio3_temperatura.py   # clase Temperatura
├── menu/
│   └── menu.py                     # crea y usa los objetos
└── README.md
```

Cada archivo de `clases/` contiene arriba la especificación (problema, entradas,
salidas, reglas, clase, atributos, contrato, algoritmo, casos de prueba y
restricciones para el agente) y abajo la implementación.

## Ejecutar

```
python menu/menu.py
```
